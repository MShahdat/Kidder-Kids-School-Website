# 🎒 Kider School Website

## 🌐 **Live Website:** https://kider-kids-school-website.vercel.app/

Kider School Website is a **fully responsive, modern educational website** designed for a kids school. The project focuses on clean UI, smooth user experience, and well-structured content presentation. It is built using **React.js** and **Tailwind CSS** with modern libraries to ensure performance, accessibility, and interactivity across all devices.


## 📌 Project Overview

This website provides essential information about the school, including academic programs, teachers, services, events, blogs, and admission appointments. It is optimized for **desktop, tablet, and mobile devices**, ensuring a seamless browsing experience for parents and guardians.


## ✨ Key Features

### 🧩 User Interface & Experience

- **Modern Header Section** displaying essential school information clearly.
- **Responsive Navigation Bar**
  - Includes child (dropdown) navigation items
  - Active page highlighted with a different color
  - Mobile-friendly menu bar that slides smoothly from the right side
- **Dark & Light Theme Toggle** for improved accessibility and user comfort.
- **Modern Footer Component** with structured and informative layout.
- **Smooth Animations** using *Framer Motion* for better visual experience.
- **404 Not Found Page** for handling invalid URLs gracefully.


### 🎠 Banner & Content Sections

- **Modern Banner Section**
  - Implemented using **React Slick Carousel**
  - Smooth slide transitions and user-friendly controls
- **Unique Class Cards**
  - Display class information including tuition fees
  - Clean, modern card-based layout
- **Services Section** showcasing facilities and services provided for children.


### 👩‍🏫 Additional Pages & Functionalities

- **Teachers Page**
  - Displays teachers’ basic information
  - Includes social media profile links
- **Appointment / Admission Page**
  - Allows parents to submit child admission details
  - Implemented using **EmailJS** for email-based data delivery
- **Testimonials Page**
  - Guardians share feedback and children’s success stories
- **Events & Blogs Section**
  - Highlights school activities, events, and educational blogs
- **Contact Page**
  - Includes school contact details
  - Integrated **map location** for easy navigation


## 🛠️ Tools & Technologies Used

- **React.js** – Frontend framework
- **Tailwind CSS** – Utility-first CSS framework for responsive design
- **React Router DOM** – Page routing and navigation
- **React Slick Carousel** – Banner and testimonial slider implementation
- **Framer Motion** – Smooth animations and transitions
- **EmailJS** – Admission appointment form email handling
- **React Icons** – Scalable icon library
- **React Toastify** – Toast notifications for user feedback
- **Netlify** – Deployment and hosting
